# Phase 7d — 初期値の摂動を土壌水分に切り替える

> 2026-10-14: この記録のスクリプト（`docs/phase7/*.py`・`docs/phase7d/*.py`）は `convection/analysis/` に移し、共通部品を `analysis/common.py` にまとめた。

## 方針（2026-10-03 決定）

浅倉さんの論文（2.1.3 摂動デザイン）に倣う。ただし格子は 2 km（今の設定のまま）。

| 項目 | 論文 | convection |
| --- | --- | --- |
| スピンアップ | 30 日。平衡に達した後に摂動を入れる | **30 日**（2000-01-01 → 01-31）。STIME = 20000131000000 |
| 大気 | 摂動なし（identical twin。土壌以外はすべて揃える） | **全 member で同じ**（スピンアップの restart をそのまま使う） |
| 摂動を入れる量 | 地表面の土壌水分 | 土壌水分（`LAND_WATER`）の**最上層**（厚さ 5 cm） |
| 摂動の形 | 一様分布のホワイトノイズ −a < x′ < a をパッチ単位で足す | 同じ |
| 振幅 a | 基準 0.01（0.2 の約 5%） | **0.01** |
| パッチ | 基準 1.5 km | **1 格子 = 2 km**（格子より細かくできない） |
| メンバー | 初期時刻・種を変えた 4 member | 20 member + mdet（真値）。種は member ごとに変え、mdet も同じ作り方 |

- 論文の結果では、ばらつきはおよそ 1 時間で始まる（2026-10-03、ユーザーから）。最初の cycle（0〜60 分）はばらつきが小さい見込み。
- これまでの初期値の摂動（下層の水蒸気 `sounding_perturb.py`・温位の乱数 `RANDOM_THETA`）は使わない。
  `RANDOM_THETA` はスピンアップの初期値（1 本）にだけ入る（対流のきっかけ）。30 日後には全 member 共通の大気の一部になっている。
- 全面陸（`LANDUSE_AllLand`）の陸面の種類は PFT 1（裸地 Desert: `STRGMAX` 0.5、`STRGCRT` 0.4。`scalelib/src/coupler/scale_landuse.F90` 191 行）。
  加えた後は 0〜0.5 に切り詰める（a = 0.01 ではまず起きない）。
- rep_asakura の元の土壌水分摂動の作り方（`run.conf` の `init_per_SM_R131_0.1_1/perturbed_restart_20000131`）は、自分の領域にも
  共同研究者の領域（読む権限なし）にも見つからなかった。論文の記述を拠りどころにする。

#### 注意: 観測のノイズは実行ごとに変わる

cycle 1 の第一推定は 1 cycle だけの実行（9829615）と同じだが、解析は違った（U の 解析/第一推定 0.908 → 0.841）。

## 同化の精度の確認 (1): 観測がある点だけで真値と比べる — 2026-10-14（ジョブなし）

指導教員の指示（計画書 Phase 7d「同化の精度の確認」）。対象は制御なしの 6 cycle（ジョブ 9844986）。

### 方法（`analysis/check_obspoint.py`）

```bash
cd analysis && STIME=20000131000000 FIGDIR=../docs/phase7d/run_soil_6cycle python3 check_obspoint.py > ../docs/phase7d/run_soil_6cycle/check_obspoint.out
```

- 観測は O = H(真値) + ε なので、O−A ではなく、ノイズを除いた d_b = H(第一推定の平均) − H(真値)、d_a = H(解析の平均) − H(真値) を観測ごとに出す。
  H(真値) は mdet の 60 分の history、第一推定・解析は restart の平均から、`common.py` の観測演算子で計算（鉛直の内挿はそれぞれの状態の気圧）。
- LETKF の obsdep（`result/obsdep/obsdep_<t>.dat`）には **QC を通った観測だけ** が入っている（cycle 6 で 75,298 個）。
  obsdep にある観測を「QC を通った観測」とし、捨てられた観測の点の値は自前の計算だけで出す。
- 確認: ε の標準偏差は全 cycle で 0.0995〜0.1008。自前の O−B・O−A と LETKF の値の差の RMS は U, V で 2〜7×10⁻⁴、T で 8×10⁻⁵
  （O−B の大きさ 0.1〜0.23 に対して 0.3% 以下）。**観測演算子は LETKF と合っている。**
- 目安（観測 1 個で考えた解析の誤差）σ_a² = σ_b² σ_o² / (σ_b² + σ_o²)、σ_o = 0.1。
  σ_b は (ア) LETKF が使うばらつき（obsdep の第一推定のばらつき × √1.45）、(イ) 実際の誤差 RMS(d_b) の 2 通り。

- 観測を使った点でも寄らず、ばらつきも足りているので、「アンサンブルの 20 member で表せる誤差の形」が限られている可能性がある。

- **U・V・T・QV は、7〜10 時間で横ばいになり、同化ありは同化なしより低いところで止まる。** 理論（`theory_da_error.md` の 8 節）の形と合う。
- スケール別に見ると、誤差の育ち方がよく分かる（`scales_long.png`）:
  8 km 未満は 5 時間ほどで飽和し、どの実験も同じ高さ。8〜16 km は 7 時間ほどで飽和。16〜32 km、32 km 以上の順に、ゆっくり育つ
  （**細かいスケールから飽和し、大きいスケールへ誤差が広がっていく**）。
  32 km 以上では、同化なしは 24 時間でもまだ育っているが、同化ありは低いところで横ばい（80 member・10 km で U 0.25、T 0.12。同化なしの約半分）。
- 16 km より細かいスケールでは、同化はまったく効かない（80 member・10 km ではわずかに悪い、+2〜4%）。

### 新たに見つかった問題: 同化ありで気圧（P）の領域平均がずれていく

| 時刻 | P の領域平均の偏り [hPa]（20 member・20 km / 80 member・10 km / 同化なし） | 偏りを除いた RMSE（同） |
| --- | --- | --- |
| 6 時 | −0.007 / −0.021 / −0.010 | 0.041 / 0.030 / 0.040 |
| 12 時 | −0.013 / −0.068 / +0.003 | 0.039 / 0.052 / 0.053 |
| 18 時 | −0.078 / −0.151 / −0.033 | 0.067 / 0.083 / 0.071 |
| 24 時 | **−0.115 / −0.215** / −0.015 | 0.063 / 0.116 / 0.058 |

- 同化ありだけ、領域平均の気圧が時間とともに下がっていく（大気の質量が減っている）。最下層ほど大きい（80 member・10 km の 24 時で層 1 が −0.36 hPa）。
  P の RMSE の増加の大部分はこの偏り。80 member・10 km では、偏りを除いた部分も同化なしの約 2 倍。
- QV も同化ありで少しずつ減っていく（80 member・10 km の 24 時で −0.039 g/kg）。T・U の偏りは小さい。
- 考えられる原因（未確認）: 領域が二重周期で、外から空気が入らないので、同化の修正で足し引きされた質量がたまっていく
  （境界のある普通の領域なら、境界から元に戻される）。P は観測していないので、U・V・T の観測から共分散を通して修正されており、
  その修正の領域平均が 0 にならない。member を増やし局所化を狭めた設定ほど大きいのは、修正の量が大きいため。

- 24 時間で確かめた 80 member・10 km の、20 member・20 km に対する全格子点の RMSE の比も、6 時間（U 0.921、T 0.898）と 24 時間（U 0.930、T 0.876）でほぼ同じ。

- inflation・RTPP・QC・同化の間隔が変えるのは、観測で見えるスケールの直し方だけで、誤差の大きな部分を占める細かいスケールには効かない。
